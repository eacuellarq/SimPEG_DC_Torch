# DC_torch Directory

This directory contains the PyTorch-modified versions of SimPEG components:

- `SimPEG/` - Complete PyTorch replacement of SimPEG core modules
- `discretize/` - Selective modifications to discretize (preserves compiled extensions)
- `solver/` - Custom solvers for torch
- `utils/` - Enhanced simulation utilities

Place your modified SimPEG modules in the appropriate subdirectories before running the installation script.
